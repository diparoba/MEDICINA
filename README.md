# MEDICINA
Aplicación web médica orientada al campo laboral que permite:

- Subir imágenes médicas (radiografías, tomografías, etc.)
- Asociarlas a partes específicas del cuerpo
- Registrar diagnósticos médicos
- Visualizar un modelo interactivo del cuerpo humano
- Hacer clic en cada parte del cuerpo para ver estudios y diagnósticos asociados

---

## 🎯 Objetivo

Facilitar el análisis médico ocupacional permitiendo almacenar estudios clínicos
y relacionarlos con zonas anatómicas específicas del cuerpo.

---

## 🛠 Tecnologías usadas

- Python
- Flask
- HTML5
- CSS3
- SQLite (base de datos local)

---

## ▶ Cómo ejecutar el proyecto

1. Instalar dependencias:

pip install flask

2. Ejecutar el programa:

python main.py

3. Abrir en navegador:

http://127.0.0.1:5000
